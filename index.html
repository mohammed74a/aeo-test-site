موقع تجريبي لاختبار AEO

هذا الموقع أُنشئ لتجربة تحسين محركات الذكاء الاصطناعي (AI Engine Optimization).

ما الذي يختبره هذا الموقع؟

  • llms.txt — بطاقة تعريف الموقع للذكاء الاصطناعي
  • robots.txt — سياسة وصول روبوتات الذكاء الاصطناعي
  • قابلية القراءة الآلية — HTML نظيف بدون JavaScript
  • ميزانية التوكنات — محتوى ضمن حدود سياق النماذج

الصفحات الرئيسية

  • الرئيسية — هذه الصفحة
  • عن الموقع — وصف المشروع التجريبي
  • الأسئلة الشائعة — أسئلة وأجوبة عن AEO

ملفات AEO

  • /llms.txt — ملف اكتشاف الذكاء الاصطناعي
  • /robots.txt — سياسة الزحف
  • /sitemap.xml — خريطة الموقع
