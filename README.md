# موقع تجريبي لاختبار AEO

موقع GitHub Pages تجريبي لاختبار تحسين محركات الذكاء الاصطناعي (AEO).

## الملفات

- `index.html` — الصفحة الرئيسية
- `about.html` — عن الموقع
- `faq.html` — الأسئلة الشائعة
- `llms.txt` — ملف اكتشاف الذكاء الاصطناعي
- `robots.txt` — سياسة وصول روبوتات AI
- `sitemap.xml` — خريطة الموقع
